## 🚀 How to Run Locally

1. Download or clone this repository
2. Open the folder in **VS Code**
3. Right-click `index.html` → **Open with Live Server**

Or simply double-click `index.html` to open in your browser.

## 🎨 Features

- **Hero Section** — Full-screen with gradient background, floating badges & CTA button
- **Navbar** — Sticky glass navbar with dark mode toggle & "Join Us" pill button
- **About Section** — 6 cards covering education, leadership, digital awareness & more
- **Programs Section** — 3 glassmorphism feature cards with hover effects
- **Gallery** — Responsive image grid with hover zoom animations
- **Stats Section** — Scroll-triggered animated counters
- **Testimonials** — Real impact stories
- **Contact Form** — Volunteer sign-up form with confetti success animation
- **Footer** — Professional footer with social links & quick navigation
- **Dark Mode** — Full dark/light theme saved in localStorage
- **Mobile Responsive** — Hamburger menu, fluid grids, touch-friendly

---

## 🛠️ Built With

- **HTML5** — Semantic markup
- **CSS3** — Flexbox, Grid, Glassmorphism, Animations
- **JavaScript (Vanilla)** — No frameworks, no dependencies
- **Google Fonts** — Playfair Display + DM Sans
- **Phosphor Icons** — Icon library via CDN
